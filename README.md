输入**公历生辰与时辰**，一键查出紫微斗数五行局（水二局 / 木三局 / 金四局 / 土五局 / 火六局）。
单页面、零依赖、可离线使用，也可直接部署到 GitHub Pages。

在线体验：把仓库部署到 GitHub Pages 后，打开 `https://<用户名>.github.io/ziwei-wuxingju/` 即可。

## 为什么需要「时辰」

五行局由 **命宫干支** 的纳音五行决定，**不是**简单地按出生年份查表：

- 命宫地支 —— 由 **生月** 与 **生时** 推出（寅宫起正月顺数至生月，落宫起子时逆数至生时）；
- 命宫天干 —— 由 **年干** 按五虎遁排十二宫天干得到；
- 五行局 —— 命宫干支查六十甲子纳音：属金为金四局、属水为水二局、属木为木三局、属土为土五局、属火为火六局。

因此完整的年月日时是查局的必要条件，这也是本工具与传统"按年查表"简易算法的区别。

## 排盘原理（安星法）

1. **公历 → 农历**：内置 1900–2100 年农历数据表；
2. **年柱**：默认以立春为年界（主流排盘口径，立春按节气精确取值），可在页面切换为「正月初一」口径（《紫微斗数全书》太阴历）；
3. **五虎遁安宫干**：甲己之年丙作首、乙庚之岁戊为头、丙辛必定寻庚起、丁壬壬位顺行流、戊癸何方发，甲寅之上好追求；
4. **安命宫**：寅宫起正月顺数至生月，落宫起子时逆数至生时；
5. **定五行局**：命宫干支 → 纳音五行 → 局。
